# 🚦 AI Traffic Management System

An AI-powered traffic control system that uses YOLOv8 and OpenCV to detect vehicles from CCTV feeds and dynamically adjust signal timings.

---

## 🚀 Features
- Real-time vehicle detection
- Lane-wise vehicle counting
- Adaptive signal timing
- 2D traffic simulation

---

## 🛠 Tech Stack
- Python
- OpenCV
- YOLOv8
- Flask (if used)
